como faço um botao html transformar uma variavel booleana de false pra true

O ChatGPT disse:
Você pode usar um botão HTML com JavaScript para mudar uma variável booleana de false para true ao clicar nele.
Exemplo simples
html
<button onclick="ativar()">Clique aqui</button>

<script>
  let ativo = false;

  function ativar() {
    ativo = true;
    console.log(ativo);
  }
</script>
Como funciona:
let ativo = false; cria a variável como falsa.
onclick="ativar()" chama a função ao clicar no botão.
ativo = true; muda o valor para verdadeiro.
console.log(ativo) mostra true no console do navegador.
Se quiser alternar entre true e false a cada clique
html
<button onclick="alternar()">Alternar</button>

<script>
  let ativo = false;

  function alternar() {
    ativo = !ativo;
    console.log(ativo);
  }
</script>
O operador ! inverte o valor booleano:
false → true
true → false
Dica: se você quer apenas transformar false em true e nunca voltar para false, use o primeiro exemplo. Se quiser alternar a cada clique, use o segundo.

Com PHP, você pode fazer isso usando um botão HTML que envia uma requisição ao servidor. Como o PHP roda no servidor, ele não altera diretamente uma variável JavaScript no navegador.

php
<?php

if (isset($_POST['ativar'])) {
    $ativo = true;
}
?>

    <button type="submit" name="ativar">Ativar</button>
</form>

<p>Estado: <?= $ativo ? 'true' : 'false' ?></p>
Como funciona:
Inicialmente, $ativo = false.
Ao clicar no botão, o formulário envia os dados para o PHP.
O PHP define $ativo = true.
A página é recarregada e mostra true.
Atenção: a variável volta para false ao recarregar a página
Isso acontece porque a variável é criada novamente a cada execução do PHP.
Se você quiser manter o valor true mesmo após o clique e a recarga, pode usar uma sessão PHP:
php
<?php
session_start();

if (!isset($_SESSION['ativo'])) {
    $_SESSION['ativo'] = false;
}

if (isset($_POST['ativar'])) {
    $_SESSION['ativo'] = true;
}
?>

<form method="POST">
    <button type="submit" name="ativar">Ativar</button>
</form>

<p>Estado: <?= $_SESSION['ativo'] ? 'true' : 'false' ?></p>
Assim, o valor permanece salvo na sessão do usuário enquanto ela estiver ativa.
Você quer que a variável fique verdadeira apenas durante essa página ou que continue verdadeira mesmo quando o usuário navegar para outra página? Isso define a melhor solução.
